# Cedar working note 2

During the trial, the pickup window is Tuesday from 2 to 5 p.m. The library
desk keeps any uncollected parcels until the next working day.

For routine handoffs, open the checklist, mark the items already reviewed, and
leave the remainder for the next shift. The checklist is a record of work in
progress, not an authorization to change the underlying arrangement. Staff can
add a short note when a handoff crosses a weekend or a public holiday.
