# Reviewed operations v1: frozen fresh holdout

Six compact, newly authored synthetic cases cover source-based operations, uncertainty and source boundaries. The author previously reviewed a consumed calculation corpus, so this set is not author-blind to that corpus; the author did not inspect v9 implementation or outputs before freezing. Keep fixture and rubric contents away from implementation until the candidate and evaluation protocol are frozen and planned inference is complete. Once any output is inspected, this set is consumed and must not be reused as fresh for tuning or confirmation.

The main paired comparison is one preregistered seed each for confirmed-operation v9 and v6 baseline, with the same local model and comparable settings. Report the automatic v9 planning arm separately if run; it tests planning and must not be mixed with the fixture-supplied plan arm. Preserve raw attempts and count errors, timeouts and cancellations. Do not retry or tune after output inspection.

`fresh.json` conforms to the existing grounding loader's case fields: `id`, original `question`, `allowed_source`, optional `excluded_source`. Every case has its own allowed source document; the excluded source is a separate collection. `confirmed_operations.json` maps every case ID to ordered operation objects using the original issue as Q1. It must be passed only to the v9 fixture-confirmed arm at its service boundary; do not expose it as a prompt or as an owner review. Record origin as `fixture_supplied`, not human-confirmed or a review outcome. Existing runner support must be extended or a wrapper used: current loader validates suite/rubric hashes but does not itself read or pass this file. The v6 baseline receives the original question, no v9 plan. Freeze implementation and runner before running this set.

The rubric defines original request coverage, operation and input selection, arithmetic or justified abstention, exact visible source evidence and unsupported claims as separate dimensions. Machine fields encode gold values and source substrings for validation aids, not autonomous substitutes for semantic review. Shared-unit expressions may be supported by a single exact source excerpt; correct equivalents and grouped answers are allowed. For conflicts conditional calculations are optional unless requested, but must be explicitly conditional and correct if supplied. A source-limited missing denominator and a zero baseline have distinct explanations.

Primary and independent reviewers assess all cases and attempts without seeing each other's scores first. Report per-case decisions, dimension-level reasons, disagreements, runtime/model/source identity and descriptive paired counts. There is no preregistered numeric pass threshold and no claim of real owner acceptance or production readiness.

From this directory run `shasum -a 256 -c MANIFEST.sha256` before inference; retain the manifest and all referenced files with results. The corpus, operation plans and rubric are frozen before any inference.
