# Mosaic working note 1

The frost alert is triggered when the orchard probe records two readings
below 1°C at least ten minutes apart. A single low reading alone does not
trigger it.

To prepare the shared working folder, staff place the latest notes beside the intake
sheet and retain the previous copy in the archive. A coordinator checks the file
name and the date before the next handoff. If a document is missing, the team
records that gap and asks for the original; a replacement is not assumed to exist.
