# Potluck 0.1.12-rc.1

An opt-in release candidate for the desktop app, with CLI 0.1.11-rc.1.
This is a preview for testing, not a stable release. Stable updater feeds and
the stable Homebrew formula are unchanged.

## What to try

- **Start locally without an account.** Choose **Use on this machine** to
  access local chat, models and memory. Sign in later to connect machines.
  Local chats and settings stay in place. This choice controls desktop chat;
  it does not switch off previously configured gateway or contribution services.
- **Pick a model for the work.** First-run suggestions account for the
  machine and intended use, distinguishing estimates from checks performed
  on that machine.
- **Give the coding CLI your project rules.** Applicable `AGENTS.md` files
  load from the repository root through the current directory and refresh
  before tasks and on session resume. Deeper directories still require the
  agent to inspect their instructions before editing.
- **Handle larger coding tasks more clearly.** Large files can be read in
  sections, context budgeting reserves reply space, and oversized prompts
  receive an actionable error.
- **See where chat goes.** Routing choices explain who can read requests.
  A locally selected chat refuses an already-loaded split model until you
  explicitly choose how to proceed.
- **Use the gateway with coding tools.** This candidate includes tool-call
  support, separate reasoning output and the Anthropic Messages route from
  the 0.1.12 work, plus stop-sequence and context-error fixes for requests
  forwarded to another owned machine. Support still depends on the model
  and serving runtime; circle/open-pool tool calls are not supported.

The coding evaluation harness now uses repeated runs, protected checks and
independent assertions. These are measurement improvements, not a claim of
new benchmark results or higher model quality.

## Downloads and testing

Use only the artifacts attached to the
[GitHub prerelease](https://github.com/newtorob/potluck-ai/releases/tag/v0.1.12-rc.1).
The release page lists the platforms actually built and validated, checksums,
and remaining limitations. Do not infer platform availability from source
compatibility. Intel Mac and Windows candidate downloads are not included.

Report the candidate version, operating system, model and steps to reproduce
when filing an issue. Exclude prompts, tokens and other private data from logs.

## Build channel

The desktop packages use the `rc` update channel at
`https://releases.trypotluck.ai/rc/0.1.12-rc.1`. Build with the committed
candidate version and pass `--publish never`,
`-c.publish.channel=rc` and
`-c.publish.url=https://releases.trypotluck.ai/rc/0.1.12-rc.1`
to electron-builder. Publish only verified candidate artifacts into that
versioned directory. Do not run the stable root-feed upload for this candidate.
