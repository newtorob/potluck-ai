# Potluck 0.1.12-rc.2

An opt-in desktop release candidate with CLI 0.1.11-rc.2. This batch contains
five reliability fixes since 0.1.12-rc.1.

## What changed

- **Incomplete coding replies stop safely.** The coding CLI refuses truncated
  or unfinished replies before executing their proposed actions or declaring
  a task complete.
- **Aider checks readiness before starting.** The launcher checks the loaded
  model and its context capacity, and budgets requests against that capacity.
  Oversized requests receive an actionable error instead of silent truncation.
- **Cancel a split-model request without always reloading.** A healthy native
  runtime can keep the model loaded after cancellation is confirmed. A stuck
  or unconfirmed cancellation still shuts the runtime down to recover safely.
- **Coding checks stay current after shell commands.** A command can change
  files even when it exits with an error. Earlier check results are now marked
  pending, and the configured check runs again before completion. A repair
  can clear a previous failure; a new break cannot reuse an old passing result.
- **Retry Settings after a connection failure.** A failed initial load shows
  a recovery action instead of an endless loading screen. Retry works in the
  same tab, and previously loaded settings remain visible if a refresh fails.

## Downloads and validation

Use the artifacts attached to the
[GitHub prerelease](https://github.com/newtorob/potluck-ai/releases/tag/v0.1.12-rc.2).
The release page lists verified platforms and checksums; `validation.json`
records build checks and their limits. Apple Silicon Mac and Linux x64 are
the candidate targets. Windows and Intel Mac downloads are not included.

These are reliability changes, not new model-quality or performance results.
Report the candidate version, platform, model and reproduction steps when
filing an issue. Keep private prompts and credentials out of reports.

## Build channel

The candidate uses the `rc` update channel at
`https://releases.trypotluck.ai/rc/0.1.12-rc.2`. Build from committed candidate
source with `--publish never`, `-c.publish.channel=rc` and
`-c.publish.url=https://releases.trypotluck.ai/rc/0.1.12-rc.2`.
Publish verified artifacts only to that versioned directory. Stable updater
feeds and the stable Homebrew formula are unchanged.
